اجرای یک Bitcoin full node روش عالی برای پشتیبانی از شبکه بیت‌کوین و تضمین غیرمتمرکز بودن آن است. یک full node تراکنش‌ها و بلاک‌ها را تأیید می‌کند و به حفظ یکپارچگی بلاک‌چین کمک می‌کند. در اینجا راهنمای گام به گام راه‌اندازی یک Bitcoin full node بر روی Windows، macOS و Linux ارائه شده است.

#### پیش‌نیازها

- **الزامات سخت‌افزاری:**
  - **پردازنده (CPU):** یک پردازنده چندهسته‌ای مدرن توصیه می‌شود. عملکرد Bitcoin Core از سرعت کلاک بالاتر بیشتر از تعداد هسته‌های بیشتر سود می‌برد. یک CPU Intel 4 Core E3v6 3.5GHz کاملاً برای یک full node بیت‌کوین کافی است.
  - **حافظه تصادفی (RAM):** حداقل 8 گیگابایت RAM توصیه می‌شود، اما RAM بیشتر می‌تواند عملکرد را بهبود بخشد. الزامات حافظه ممکن است با رشد اندازه بلاک‌چین بیت‌کوین افزایش یابد.
  - **ذخیره‌سازی:** بلاک‌چین بیت‌کوین به طور مداوم در حال رشد است، بنابراین شما نیاز به فضای ذخیره‌سازی کافی برای جای دادن آن دارید. یک درایو SSD یا NVMe برای همگام‌سازی سریع‌تر و عملکرد بهتر نسبت به HDD (هارد دیسک) توصیه می‌شود. حداقل 1TB فضای دیسک SSD/NVMe مورد نیاز است و 2TB توصیه می‌شود زیرا بلاک‌چین بیت‌کوین به سرعت در حال رشد است.
  - **اتصال اینترنت:** اتصال اینترنت پرسرعت و پایدار برای نگه داشتن node شما همگام با شبکه بیت‌کوین ضروری است. اتصال 100Mbps با 5 تا 10TB پهنای باند در ماه کافی است.

- **الزامات نرم‌افزاری:**
  - **سیستم‌عامل:** Bitcoin Core، پیاده‌سازی مرجع برای یک Bitcoin full node، با سیستم‌عامل‌های مختلف از جمله Windows، macOS و Linux سازگار است. سیستم‌عاملی انتخاب کنید که با آن راحت هستید و به خوبی توسط Bitcoin Core پشتیبانی می‌شود.
  - **نرم‌افزار Bitcoin Core:** آخرین نسخه نرم‌افزار Bitcoin Core را از [وب‌سایت رسمی](https://bitcoin.org/en/download) دانلود و نصب کنید.

- **ملاحظات امنیتی:**
  - **پیکربندی فایروال:** اطمینان حاصل کنید که فایروال شما اتصالات ورودی به پورت 8333 (پورت پیش‌فرض برای شبکه peer-to-peer بیت‌کوین) را برای قادر کردن node شما به اتصال با سایر node های شبکه بیت‌کوین اجازه می‌دهد.
  - **به‌روزرسانی نرم‌افزار:** به طور منظم نرم‌افزار Bitcoin Core خود را به آخرین نسخه به‌روزرسانی کنید تا از اصلاحات امنیتی و بهبودها بهره‌مند شوید.
  - **امن کردن Node شما:** بهترین روش‌ها برای امن کردن سرور خود را پیاده کنید، مانند استفاده از رمزهای عبور قوی، به‌روز نگه داشتن سیستم‌عامل و اعمال هر اقدام امنیتی اضافی توصیه شده برای محیط خاص شما.

### راه‌اندازی یک Bitcoin Full Node بر روی Windows

1. **دانلود Bitcoin Core Client:**
   - از [صفحه دانلود Bitcoin Core](https://bitcoincore.org/en/download/) بازدید کنید.
   - نسخه مناسب برای Windows را انتخاب کنید و نصب‌کننده را دانلود کنید.

2. **نصب Bitcoin Core:**
   - نصب‌کننده را اجرا کنید و دستورالعمل‌ها را دنبال کنید.
   - دایرکتوری برای نصب Bitcoin Core انتخاب کنید. دایرکتوری پیش‌فرض معمولاً مناسب است.

3. **اجرای Bitcoin Core:**
   - Bitcoin Core را از منوی Start باز کنید.
   - اولین بار که Bitcoin Core را اجرا می‌کنید، می‌پرسد کجا می‌خواهید داده‌ها را ذخیره کنید. دایرکتوری با حداقل 350 گیگابایت فضای خالی انتخاب کنید.
   - Bitcoin Core شروع به دانلود بلاک‌چین می‌کند. این می‌تواند چندین روز طول بکشد، بسته به سرعت اینترنت شما.

4. **پیکربندی Node:**
   - فایل `bitcoin.conf` واقع در دایرکتوری داده بیت‌کوین (پیش‌فرض: `C:\Users\YourUsername\AppData\Roaming\Bitcoin\bitcoin.conf`) را ویرایش کنید.
   - خطوط زیر را به فایل اضافه کنید تا node خود را پیکربندی کنید:
     ```plaintext
     server=1
     txindex=1
     ```
   - فایل را ذخیره کرده و ببندید.

5. **اجازه اتصالات:**
   - تنظیمات فایروال خود را باز کنید و اتصالات ورودی به پورت 8333 را اجازه دهید.

### راه‌اندازی یک Bitcoin Full Node بر روی macOS

1. **دانلود Bitcoin Core Client:**
   - از [صفحه دانلود Bitcoin Core](https://bitcoincore.org/en/download/) بازدید کنید.
   - نسخه macOS نصب‌کننده را دانلود کنید.

2. **نصب Bitcoin Core:**
   - فایل .dmg دانلود شده را باز کنید و Bitcoin Core را به پوشه Applications خود بکشید.

3. **اجرای Bitcoin Core:**
   - Bitcoin Core را از پوشه Applications باز کنید.
   - زمانی که درخواست شد، دایرکتوری با حداقل 350 گیگابایت فضای خالی برای ذخیره داده‌های بلاک‌چین انتخاب کنید.
   - Bitcoin Core شروع به دانلود بلاک‌چین می‌کند که ممکن است مدتی طول بکشد.

4. **پیکربندی Node:**
   - فایل `bitcoin.conf` واقع در دایرکتوری داده بیت‌کوین (پیش‌فرض: `~/Library/Application Support/Bitcoin/bitcoin.conf`) را ویرایش کنید.
   - خطوط زیر را اضافه کنید:
     ```plaintext
     server=1
     txindex=1
     ```
   - فایل را ذخیره کرده و ببندید.

5. **اجازه اتصالات:**
   - به System Preferences > Security & Privacy > Firewall بروید.
   - اتصالات ورودی به Bitcoin Core را اجازه دهید.

### راه‌اندازی یک Bitcoin Full Node بر روی Linux

1. **دانلود Bitcoin Core Client:**
   - به [صفحه دانلود Bitcoin Core](https://bitcoincore.org/en/download/) بروید.
   - نسخه Linux مناسب برای توزیع شما را دانلود کنید.

2. **نصب Bitcoin Core:**
   - ترمینال باز کنید و به دایرکتوری که فایل را دانلود کرده‌اید بروید.
   - tarball را استخراج کنید و Bitcoin Core را نصب کنید:
     ```bash
     tar -xzf bitcoin-*.tar.gz
     sudo install -m 0755 -o root -g root -t /usr/local/bin bitcoin-*/bin/*
     ```

3. **اجرای Bitcoin Core:**
   - Bitcoin Core را با اجرای `bitcoind` در ترمینال شروع کنید.
   - دایرکتوری با حداقل 350 گیگابایت فضای خالی برای ذخیره داده‌های بلاک‌چین انتخاب کنید.
   - Bitcoin Core شروع به دانلود بلاک‌چین می‌کند. این می‌تواند چندین روز طول بکشد.

4. **پیکربندی Node:**
   - فایل `bitcoin.conf` واقع در دایرکتوری داده بیت‌کوین (پیش‌فرض: `~/.bitcoin/bitcoin.conf`) را ویرایش کنید.
   - خطوط زیر را اضافه کنید:
     ```plaintext
     server=1
     txindex=1
     ```
   - فایل را ذخیره کرده و ببندید.

5. **اجازه اتصالات:**
   - فایروال خود را برای اجازه اتصالات ورودی در پورت 8333 پیکربندی کنید.

### نتیجه‌گیری

اجرای یک Bitcoin full node روش پاداش‌دهی برای پشتیبانی از شبکه بیت‌کوین است. این امر نیازمند مقداری راه‌اندازی اولیه و نگهداری مداوم است، اما تضمین می‌کند که شما یک node کاملاً تأیید‌کننده دارید که به حفظ یکپارچگی شبکه کمک می‌کند. اطمینان حاصل کنید که سیستم شما امن و به‌روز باقی می‌ماند و از بخشی بودن از جامعه غیرمتمرکز بیت‌کوین لذت ببرید.
